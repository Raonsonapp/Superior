## Quick orientation

Superior AI is currently a **pre‑MVP** Flutter (mobile/web/desktop) client backed by Go/Gin services calling Qwen3‑8B via the HuggingFace Router.

The specification maps the path from this point to an enterprise‑scale platform comparable to ChatGPT, Claude, Gemini, Grok, Perplexity, and Copilot.

**Start here:** the *Quick wins* and *Phase 1 — MVP* sections at the end of [SPECIFICATION.md](./SPECIFICATION.md).
